# نشر سوق الشرجي على Vercel

## الطريقة الصحيحة

1. فك ضغط الملف أولاً.
2. ارفع **محتويات المجلد** إلى Vercel أو اربط مستودع GitHub.
3. إذا ظهر خيار Framework اختر `Other` أو اتركه بدون Framework.
4. اترك Build Command فارغاً.
5. اترك Output Directory فارغاً.
6. اضغط Deploy.

لا ترفع ملف `index.html` وحده؛ يجب رفع `index.html` مع `style.css` و`script.js` و`sync.js` ومجلد `assets` وباقي الملفات.

## مهم بخصوص البيانات

Vercel يشغّل هذه الحزمة كواجهة static، لذلك الحسابات والإعلانات في هذه النسخة تحفظ داخل متصفح المستخدم عبر LocalStorage. المزامنة مع `server.js` تتوقف تلقائياً عندما لا يكون API موجوداً، حتى لا تتعطل الواجهة.

إذا تريد أن يرى المستخدم الإعلان من جهاز آخر أو من حساب آخر، تحتاج لاحقاً إلى قاعدة بيانات خارجية مثل PostgreSQL أو Supabase أو Firebase. لا تستخدم `data.json` للحفظ الدائم على Vercel لأن ملفات Vercel ليست مساحة تخزين دائمة.

## إذا كان عندك VPS أو سيرفر Node

استخدم بدلاً من ذلك:

```bash
npm install --omit=dev
npm start
```

هذه الطريقة تشغّل `server.js` وتوفر API والمزامنة.
